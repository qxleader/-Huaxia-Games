帮助中心

关于账号、资助、投稿、赛事与启动器的常见问题，都在这里。找不到答案，欢迎在讨论区提问。

Q：华夏游戏账号什么时候能用？▾
官网备案后正式上线账号体系，支持邮箱 / 手机号注册，并开放微信、QQ、哔哩哔哩第三方快捷登录。当前为静态原型，登录 / 注册仅作演示，不保存信息。
Q：第三方登录合规吗？▾
备案后会按国家法律法规接入合规第三方登录；备案前为降低合规风险，仅保留入口，暂不开放。
Q：创作者身份有哪些？▾
浏览者 / 创作者 / 资助者 / 赛事评委 / 制作组成员。制作组成员（如津门制作组）有专属墨龙徽章，身份分层参考主流游戏平台。
Q：资助和购买游戏有什么区别？▾
资助是纯自愿支持，不是购买。平台全站免费，游戏内容不会锁在任何资助档位之后，资助仅获电子荣誉、素材包、内测资格等权益。详见资助中心。
Q：资助后能退款吗？▾
持续资助可随时取消后续扣款；单笔资助设有时间窗口，窗口期内满足条件可申请退款，超出时限、资金已投入开发则不再退款。规则参考主流商店的时间窗口做法，写入资助协议。
Q：资助的钱花在哪、怎么公示？▾
以二十四节气为节点公示，列明服务器带宽、美术素材、赛事物料、周边打样等去向，在保护隐私前提下最大化公开。详见资金公示。
Q：什么样的团体算"创作团体"？▾
只要与游戏、动画相关——做游戏的、配音的、剪辑的、摄影的、美术的、后期的——都算平台上的创作团体，都可入驻并投稿作品。
Q：投稿作品版权归谁？▾
作品版权归作者本人，平台仅获得非商业的展示与宣传权。二次剪辑、赛事集锦等会逐一征求作者同意。
Q：作品被举报侵权怎么办？▾
平台提供原创识别与版权存证指引（费用作者自理），一旦确证侵权即下架，责任由侵权方自负。详见投稿与版权指引。
Q：比赛收报名费吗？▾
不收取任何报名费用，证书仅作荣誉纪念，不具备行政或职业资质效力。详见赛事中心。
Q：新手也能参赛吗？▾
可以。赛事分新手组与进阶组，照顾不同阶段创作者，防止老手持续包揽奖项。评审采用大众投票 + 评委评审的混合模式。
Q：华夏游戏启动器什么时候上线？▾
启动器为远期规划，一期官网的下载页已做原型展示。正式版将提供 Windows / macOS / Linux 安装包，包含游戏库、云存档与内置创作工具。详见平台下载。
Q：启动器有哪些特色？▾
作品库管理、一键安装、云存档、内置简易剧本编辑器 / 公共素材库 / 开发日志编辑器，未来接入自研魔镜与长城引擎生态。
Q：平台做付费内容吗？▾
现阶段全站免费，不做任何付费内容，仅预留框架。未来若上架付费游戏，可适当提供付费解锁的特权，但绝不靠资助解锁游戏内容。
Q：平台对广告和引流怎么处理？▾
平台零容忍广告与恶意引流，对违规内容将依规处理，保护社区氛围。
